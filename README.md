# Project 1 Streamlit Dashboard

## Struktur folder

Letakkan folder `project1_output` hasil Colab di folder yang sama dengan `app.py`.

```text
project_dashboard/
├── app.py
├── requirements.txt
└── project1_output/
    ├── fact_sales.csv
    ├── dim_customer.csv
    ├── dim_product.csv
    ├── dim_country.csv
    ├── dim_date.csv
    └── file output lainnya
```

## Cara menjalankan

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Halaman dashboard

1. Overview
2. Sales Performance
3. Customer Segmentation
4. Business Recommendation
5. Data Model & Methodology

## Catatan laporan

Dashboard ini digunakan sebagai reporting tool interaktif berbasis Python/Streamlit. Untuk BAB 4 Rekognisi Mata Kuliah, screenshot halaman Overview, Sales Performance, Customer Segmentation, Business Recommendation, dan Data Model & Methodology dapat digunakan sebagai bukti output Project 1.
